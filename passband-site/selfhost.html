Passband

Self-host

Run the daemon on your own box, keep your mail on your own disk.

Passband is two pieces. squelchd is the daemon: it syncs your Gmail read-only, triages it, and serves it over a local API. Passband is the Mac app that talks to the daemon. You host the daemon; the app connects to wherever it lives.

1. Create a Google OAuth client

  1. Go to console.cloud.google.com and create a project
  2. Enable the Gmail API
  3. Configure the OAuth consent screen (External) and add yourself as a test user
  4. Create credentials: OAuth client ID, type Desktop app

2. Run the daemon

Prebuilt multi-arch images (amd64 + arm64) are public on GHCR, no registry login needed: 

docker pull ghcr.io/braelyn-ai/squelchd:latest

A minimal docker-compose.yml:

services:
  squelchd:
    image: ghcr.io/braelyn-ai/squelchd:latest
    restart: unless-stopped
    ports:
      - "127.0.0.1:8848:8848"
    volumes:
      - squelch-data:/data
    environment:
      SQUELCH_ACCOUNT_EMAIL: you@gmail.com
      SQUELCH_CLIENT_ID: ${SQUELCH_CLIENT_ID:?set in .env}
      SQUELCH_CLIENT_SECRET: ${SQUELCH_CLIENT_SECRET:?set in .env}

volumes:
  squelch-data:

The port stays on loopback; front it with tailscale serve --bg 8848 or your own proxy to reach it from your Mac. The full environment-variable reference and the OAuth consent flow live in deploy/DOCKER.md, and docs/GETTING-STARTED.md walks a complete setup end to end: daemon in Docker on a NAS, Passband on a Mac.

3. Get the app

Download Passband for Mac, or:

brew install --cask braelyn-ai/tap/passband

Point it at your daemon, pair the device, and you're done. Updates arrive in-app via Sparkle.
